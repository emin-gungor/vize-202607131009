# Veritabanı Yönetim Sistemleri Vize Projesi

## Senaryo

Alan: Logistics & Delivery (Lojistik ve Teslimat)

Sistem: Computer Vision Camera (Görüntü İşleyen Kamera)

Yapay Zeka Bileşeni: Anomaly Detection (Anomali Tespiti)

## Projenin Amacı

Bu projede lojistik ve teslimat alanında görüntü işleyen kameralarla anormal durumların tespit edilmesi konusu ele alınacaktır.

Amacım, bu senaryoya uygun bir veri kaynağı bulmak ve verileri SQL sorgularıyla incelemektir.
